업무 대시보드 리뉴얼
1. Firebase Firestore 규칙에 firestore.rules.txt 전체 내용을 게시하세요. 기존 규칙을 덮어쓰기 전 백업하세요.
2. GitHub에 ZIP 내 파일을 업로드하세요.
3. 로그인 후 오늘의 업무 페이지로 이동합니다. 관리자는 업무 배정 페이지에서 직원별 업무를 등록하고 날짜별 완료 여부를 확인할 수 있습니다.
4. users/{uid} 문서에 name, position, role(admin 또는 직원 역할) 정보가 필요합니다.
5. 기존 로그인/보관함/기록지 기능은 유지됩니다.
6. 관리자 업무 목록 조회는 해당 날짜의 업무를 표시하며 직원 목록 읽기는 관리자만 가능합니다.
7. Firebase 실제 배포 환경 테스트는 수행하지 않았습니다.
