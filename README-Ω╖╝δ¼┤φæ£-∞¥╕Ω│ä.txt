업무관리 업데이트
- 근무표 엑셀 업로드: 관리자 업무 배정 페이지에서 업로드. 엑셀의 근무자 이름은 Firebase users.name과 일치해야 합니다.
- O/○, △, ●, ⊙: 근무; X/Ⅹ, -, ―, ◐: 휴무.
- 좌측 업무를 우측 직원에게 드래그하면 주담당. 부담당은 업무 선택 후 직원의 부담당 배정 버튼으로 지정합니다. Shift+드래그로도 부담당 지정 가능.
- 주담당이 근무하는 날 주담당, 휴무인 날 부담당이 근무할 때 부담당이 담당합니다. 근무표 미등록 날짜는 담당 미확정 처리됩니다.
- 직원은 인계 요청을 보낼 수 있고, 상대방이 수락하면 해당 회차의 완료 담당자가 바뀝니다.
- 새 firestore.rules.txt를 Firebase 규칙에 게시해야 합니다.
- 기존 taskAssignments 데이터는 유지합니다.
주의: 완료 기록은 회차별로 저장됩니다. 월간/주간 업무의 인계도 해당 회차에 적용됩니다.
주의: 이 버전은 Firestore에 접속한 실운영 테스트를 거치지 않았습니다.
